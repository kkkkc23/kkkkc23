模型与适用范围

结果是独立、正态的局部随机失配估计，主要针对设定镜像比的 M1/M2。M3/M4 的失配通常主要改变内部节点电压；它们通过有限输出电阻、体效应和接近饱和边界造成的二阶影响未计入。要得到完整 cascode 的 PVT + Monte Carlo 结果，应使用工艺 PDK 的 BSIM 模型仿真。

计算原理与公式

1. Pelgrom 阈值失配σ(ΔVTH) = AVt·√[1/(WM1LM1) + 1/(WM2LM2)]。输入的 AVt 单位为 mV·µm，W、L 使用 µm。
2. 电流因子失配σ(Δβ/β) = Aβ·√[1/(WM1LM1) + 1/(WM2LM2)]。输入的 Aβ 单位为 %·µm。
3. 阈值电压转成电流误差VOV = √[2·IREF / (k′n·WM1/LM1)]；σVT贡献 = 2·σ(ΔVTH)/VOV。低过驱动电压会显著放大 VTH 的随机偏差。
4. 合成随机匹配误差σ(ΔI/I) = √[(2σ(ΔVTH)/VOV)² + σ(Δβ/β)²]。页面报告 1σ、3σ 和 6σ；3σ 对应约 99.73% 的正态分布范围，6σ 用于更保守的设计裕量评估。
提示：请使用对应工艺、温度和器件类型的 PDK 统计参数 AVt 与 Aβ。本页的结果是 M1 与 M2 的局部随机失配；扩大两管有效面积能降低随机误差，但不能消除输出电压、有限输出电阻或版图梯度带来的系统误差。
